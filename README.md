# 🚀 Artificial Intelligence: The Next Frontier

An interactive, animated 10-slide executive HTML presentation deck covering the fundamentals, economic impact, architectures, and future roadmap of Artificial Intelligence.

![Tech Stack](https://img.shields.io/badge/Tech--Stack-HTML5%20%7C%20CSS3%20%7C%20JS-blue)
![Platform](https://img.shields.io/badge/Platform-GitHub%20Pages-brightgreen)

---

## 🌟 Features

- **Responsive Design:** Dark-mode glassmorphic interface built for high-resolution displays.
- **Fluid Animations:** Staggered CSS & JavaScript entrance transitions on every slide transition.
- **Dual Navigation:** Supports keyboard controls (`Left` / `Right` / `Space`) and touch/mouse on-screen controls.
- **Progress Tracking:** Real-time top progress bar indicator and dynamic slide counter.
- **Zero Dependencies:** Pure HTML/CSS/JS without external framework overhead.
